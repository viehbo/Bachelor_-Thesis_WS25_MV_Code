\section{Motivation}
\label{sec:introduction:motivation}
Climate change represents a multidimensional global challenge with significant environmental, economic, and societal implications. Artificial Intelligence (AI) is increasingly recognized as a promising tool for climate modeling and data-driven Earth system analysis \parencite{stern_climate_transition_2025}. However, the performance of AI systems strongly depends on the quality, structure, and relevance of the underlying data. Before model training, careful preprocessing, feature assessment, and dimensionality reduction are essential.

In practice, substantial computational resources are often consumed by iterative 'trial-and-error' model experimentation based on weak or insufficient data preselection. This issue becomes particularly relevant in meteorological research, where datasets exhibit extremely high spatial and temporal resolution. Simply incorporating all available variables into a model and interpreting the outcome is neither computationally efficient nor scientifically rigorous. And on consumer hardware simply impossible.

As shown in Table~\ref{tab:era5_land_dimensions}, the ERA5-Land dataset alone consists approximately 1.65 million spatial grid cells with 75 years of hourly observations (reanalyzed). This results in an extraordinarily large and highly multidimensional data space.

\textit{glaciVis} is designed to address this challenge. The system enables structured visual exploration of large-scale meteorological datasets and supports the identification of potentially relevant variables prior to machine learning model development. By providing interactive analytical tools, it allows researchers to evaluate whether specific observations are suitable candidates for predictive modeling tasks.

\section{Objectives and Approach}
\label{sec:introduction:objectives}
The initial objective of this work was to visually compare glacier-related data with meteorological variables derived from ERA5.
The underlying hypothesis was that significant correlations between glacier dynamics and specific atmospheric or land-surface variables could be identified. 
Such relations would represent promising feature candidates for a subsequent machine learning task aimed at predicting glacier melt and, potentially, uncovering contributing factors beyond temperature alone.

Although the intended identification of strong predictive relationships proved more challenging than anticipated, the exploratory analysis of the ERA5 dataset yielded valuable insights.
In particular, the visualization-driven investigation significantly improved the understanding of variable behavior, seasonal patterns, and long-term trends within the dataset.

This project builds upon prior work conducted within the course \textit{Practical Work in AI (364055, 2024W)} during the winter semester 2024.
The methodological insights gained in that context accelerated the development of this thesis and contributed to a more systematic strategy for data preprocessing, integration of heterogeneous data sources, and interactive visualization design.

Given the substantial data volume, high temporal resolution, and multidimensional structure of the ERA5 dataset, a dedicated preprocessing and visualization pipeline was developed to ensure scalability, interpretability, and analytical reliability. While the original prediction objective was only partially achieved, the resulting framework \textit{glaciVis} provides a robust foundation for structured feature exploration for future machine learning applications.

\section{Use of AI Tools}
\label{sec:use_of_ai}
Throughout this project, AI-based tools were used both explicitly through
direct prompting and implicitly through features integrated into the
development environments.

\paragraph{Explicit use:}\mbox{}\\

\textbf{Programming:} ChatGPT and Claude were used for navigating package
documentation and debugging. Where these tools contributed substantially to the
implementation, this is documented as comments in the source code.

\textbf{Writing:} ChatGPT, Claude, and DeepL were used to check grammar and
spelling, and in some cases to reformulate individual sentences for clarity.
All content, unless explicitly cited, was written by myself.

\paragraph{Implicit use:}\mbox{}\\

Development environments such as PyCharm and Overleaf provide built-in
AI-driven features for code suggestions, error detection, and grammar
checking. While these tools were active during development, they do not
contribute to the substantive content of this work and are mentioned here
solely for transparency.
