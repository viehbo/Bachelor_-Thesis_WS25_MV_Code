
\section{User Interface}

The user interface is designed as an analytical preselection tool rather than a purely visual dashboard. Its purpose is to support systematic exploration of candidate features for machine learning tasks.

Each section contributes to a specific stage of feature understanding:

\begin{itemize}
    \item File selection defines the spatial and temporal scope.
    \item Adjustments and controls enable variable selection and filtering.
    \item The map supports spatial pattern inspection.
    \item The time series plot allows temporal trend analysis.
\end{itemize}
